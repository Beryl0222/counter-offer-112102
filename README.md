# 金饰活动话术与预留有效性

金饰门店活动群、实物清单及客服来信。材料中的人、机构及经营记录是合成的。

每份资料为 UTF-8 JSON 数组。id 在同一份资料内唯一，原始文字按收到的形式保留。

- `data/policy.json`。活动群对话。role=经理授权/发布/转发分别表示有权更正、可发布、新增不了授权。时刻为门店当地时间。
- `data/inventory.json`。单位重量 g，gram_price 为基础金料价，fixed_price 为固定含工费总价。holdable=false 是货品目录明确禁止留货，null 表示等待门店确认。
- `data/customers.json`。客服记录。at 为记录时间，request 是归属同一客户组合的多条来信的引用。外部柜台单可已有签字，原承诺来自旧手工操作。

使用 Python 3.11 标准库，无需安装软件包或连接外部服务。

以下命令分别读取一份原始资料、检查资料中的字段与关联。

```sh
python3 -m json.tool data/policy.json
python3 -m unittest discover -s tests -v
```

## 程序

`goldstore/` 把三份资料接成一日流程：

- `policy.py` 活动群原文 → 结构化店规。经理授权可更正、发布可进报价、转发只登记为未授权说法；每条规则都带来源句作证据，并分清限定的是某一店、按克件、定价款、单件还是整套。
- `pricing.py` 报价引擎。识别价签类别（按克＝金料价＋工费／定价款＝固定总价）与计量口径（按克优惠只扣金料、工费不打折、定价件不计金料门槛）；说明哪些件参加、优惠落在哪件、什么时候截止；未授权话术一律不承诺，可按已确定部分或原价试戴。
- `holds.py` 留货登记。同一库存单件同一时刻只能留住给一个顾客；holdable=null 待门店确认、false 不可留；带状态历史，可回查任一时刻的占用。
- `pipeline.py` 按时序接入活动群、客服来信与到点时钟：正常调价只影响后续确认；更正揭示原承诺落在不允许留货的件时暂停兑现、释放该件、保留合法件并给出替代选择与门槛对照；等候单在件空出时按登记先后补位。
- `report.py` 交班报告：每句活动怎样作用到报价、实际占用的件、仍需联系谁确认、全部报价明细。

```sh
python3 main.py              # 一日时间线＋交班报告
python3 main.py --data DIR   # 指定资料目录
```

口径说明：P2 的「券面两百」按该消息内两张券（换旧返券、套装券）面额各两百计；套装券是两件及以上订单的活动权益，会员可与换旧返券同用，非会员未明说可同用就不叠。同名「白鹭日」在东桥（按克减＋券）与西渡（定价按件减、不叠换旧券）是两套规则，互不使用。
